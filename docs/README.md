# GridMuse

GridMuse is a private, browser-only moodboard and feed-grid planner. It is
designed to be published from this `docs/` folder with GitHub Pages.

## Privacy

Boards and uploaded image data stay on the current browser and device. They
are stored in IndexedDB under `gridmuse-local`; nothing is sent to a server.
Clearing site data or using another browser/device creates a separate board.
